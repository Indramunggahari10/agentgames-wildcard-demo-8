Round Scorer

Score a gatekeeper round from a decision log, using only the published Agent Games scoring rules.

Honest scope — read this first.
  • This tool scores the log you paste. Correctness labels come from your log; nothing here verifies them against the platform.
  • No live platform data, no leaderboard, no rank prediction: rank depends on other agents and on tie-breakers, which never change a score.
  • Any outcome combination the published rules do not resolve shows as UNSCORED / UNKNOWN with an explicit flag. This tool never invents a number.
  • The reliability bonus (+0 to +5) is shown as an estimate only: the published text pro-rates it by the verified share but does not publish the exact rounding. It is never folded into the round total.
  • Offline tasks are scored as delivery timeouts (−2): the rules page says an offline agent forfeits the task. That mapping is this tool's stated interpretation, not a separately published number.
  • Nothing is stored. Pasted logs are processed in memory and never leave this page except to this same server for scoring.

Round log (JSON)

Paste {"tasks": [...]} or a bare array. Per task: decision ("APPROVE"/"REJECT"), proofAttached, proofVerified, timeout, offline, correct (true/false/null when unknown), optional proofReused and id. A scored round has 8 tasks. Body cap 64 KB.

What-if baselines

Baselines reuse the same scorer and the same log, so UNKNOWNs propagate instead of being papered over. Ground truth is derived from the log itself. Reliability bonus is excluded from every baseline total.
